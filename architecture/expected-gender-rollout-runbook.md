# Expected Gender Rollout Runbook

This runbook is for the legacy expected gender remediation rollout in `proj-coach-backend`.

It assumes the backend code, regression tests, dry-run tooling, staged reindex tooling, and internal frontend cleanup are already merged or checked out locally.

## Preconditions

- Use a write-capable production MongoDB credential. The read-only analytics credential is not sufficient.
- Use a backend shell that already has valid production config access for MeiliSearch.
- Keep `SKIP_EXTERNAL_SERVICE_CONNECTIONS=1` for script-driven reindex runs so Redis/RabbitMQ/Slack/Loki are not required.
- Do not start the Meili reindex until the Mongo normalization write has completed successfully.

## Read-Only Artifacts

These files are generated by the dry-run tooling:

- `/tmp/expected-gender-migration-plan.json`
- `/tmp/expected-gender-reindex-plan.json`
- `/tmp/expected-gender-reindex-userid-chunks.json`

## Step 1: Mongo Normalization Write

Dry-run first:

```bash
MONGO_URI="mongodb+srv://<write-user>:<write-password>@prodcluster.pyr2ag.mongodb.net/ditto" \
bun run scripts/migrate-expected-gender.ts \
  --json /tmp/expected-gender-migration-plan.json
```

Execute the write:

```bash
MONGO_URI="mongodb+srv://<write-user>:<write-password>@prodcluster.pyr2ag.mongodb.net/ditto" \
bun run scripts/migrate-expected-gender.ts \
  --execute \
  --yes \
  --json /tmp/expected-gender-migration-executed.json
```

Expected effect:

- normalize legacy `Female` to `Women`
- normalize legacy `Male` to `Men`
- collapse mixed legacy/canonical duplicates introduced by that mapping

## Step 2: Export Fresh Reindex Plan

Immediately regenerate the reindex candidate list after the Mongo write:

```bash
MONGO_URI="mongodb+srv://<write-user>:<write-password>@prodcluster.pyr2ag.mongodb.net/ditto" \
bun run scripts/export-expected-gender-reindex-plan.ts \
  --json /tmp/expected-gender-reindex-plan.json \
  --ids-json /tmp/expected-gender-reindex-userid-chunks.json
```

## Step 3: Staged Meili Reindex

Dry-run a single chunk first:

```bash
SKIP_EXTERNAL_SERVICE_CONNECTIONS=1 \
bun run scripts/reindex-expected-gender-users.ts \
  --ids-json /tmp/expected-gender-reindex-userid-chunks.json \
  --chunk-index 0
```

Execute a bounded chunk range:

```bash
SKIP_EXTERNAL_SERVICE_CONNECTIONS=1 \
bun run scripts/reindex-expected-gender-users.ts \
  --ids-json /tmp/expected-gender-reindex-userid-chunks.json \
  --from-chunk 0 \
  --to-chunk 9 \
  --execute \
  --json /tmp/expected-gender-reindex-run-0-9.json
```

Repeat until all chunks are complete.

## Step 4: Post-Reindex Proof

Verify live Meili docs against Mongo after the reindex completes:

```bash
CONFIG_PATH=./config/config.toml \
bun run scripts/verify-expected-gender-meili-docs.ts \
  --ids-json /tmp/expected-gender-reindex-userid-chunks.json \
  --json /tmp/expected-gender-meili-verification.json
```

Expected post-write outcomes:

- expected gender migration candidates collapse to zero or near-zero
- Meili verifier mismatches collapse to zero or to an explainable residual tail if writes were partial
- internal matchmaker facets no longer show separate `Female/Male` buckets for migrated users

## Step 6: Manual Smoke Checklist

- In `ditto-internal-frontend`, open the operator profile edit dialog and verify expected gender offers `Women`, `Men`, `Nonbinary`, `Everyone`.
- In `ditto-internal-frontend`, edit a user from legacy `Female` or `Male` to confirm the saved payload uses canonical labels.
- In Matchmaker V2 and LoveYacht, confirm a user with expected gender `Women` behaves identically to a legacy `Female` profile in autofilter.
- In Matchmaker V2, confirm the `Expected Gender` facet no longer shows separate `Female/Male` buckets after reindex completes.

## Rollback Notes

- The Mongo normalization script is a one-way data cleanup. There is no automatic rollback script.
- Before running Step 1, ensure there is a durable export or snapshot strategy for the affected `user_profiles` documents if rollback is required.
- The Meili reindex is safe to rerun; it is derived state.
